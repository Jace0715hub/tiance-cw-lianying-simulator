# 机制规格（v0.1）

## 时间

- 内部时间为整数帧，`16 帧 = 1 秒`。
- 增益区间使用半开区间 `[开始帧, 结束帧)`。
- 橙武最后一发按龙牙施展帧判断：`castFrame < orangeUntil`。
- 一个动作包由前置非 GCD、主要动作和 GCD 末端非 GCD组成。

## 已确认的大橙武规则

- 主动不占 GCD。
- 主动可以与龙吟、撼如雷同时按下。
- 主动立即将战意设为 5。
- 主动持续 6 秒，冷却 50 秒。
- 窗口内龙吟无调息时间。
- 窗口内龙牙先扣除战意，命中后再回复至 5 点。
- 窗口边界运行时仍按龙牙施展时判断。M5.29已证明当前正式轴及四条近优轴的末牙至少提前`1067.5ms`施展，因此只要真实命中延迟严格小于该值，改按命中时判断也会得到完全相同的回豆、附伤和后续状态；超过该边界时不外推结论。

## 连营与龙牙

- 模拟配置使用 `rotation=lianying|muyun` 明确循环类型，默认研究配置为 `lianying`。
- 激雷期间，连营龙牙消耗 1 点战意。
- 牧云龙牙以及激雷外的连营龙牙消耗 3 点战意。
- 马下龙牙增加 1 层龙驭。
- 马上且存在龙驭层数时，龙牙消耗 1 层并获得龙驭强化标记。
- 伤害数值由独立 damage oracle 解释；状态机不硬编码百分比。
- 马上无法直接施展任驰骋；必须先下马，再施展任驰骋。
- 技能表将马上的任驰骋行编译为“下马→任驰骋”；状态机本身仍会拒绝没有下马动作的直接施展。
- 任驰骋在读条完成并成功上马时，把断魂刺调息刷新为立即可用；事件同时保留刷新前CD和刷新时刻供审计。
- 撼如雷必须等任驰骋读条结束后才能施展；任驰骋读条短于一个GCD，因此通常在读条完成后利用剩余GCD空档接雷。橙武主动和主动下马本身不造成这一限制，也不能绕过尚未完成的任驰骋读条。
- 已确认任驰骋15秒攻击增益与马上状态分开：主动下马不清除该增益，后续马下技能仍按剩余持续时间享受伤害加成。结构审计会显式标记依赖这一机制的技能。

## 龙牙状态转移顺序

1. 在施展帧快照激雷、橙武、驰骋、流血、马上状态和施展前战意。
2. 检查战意并扣除 1 或 3 点。
3. 判断并更新龙驭生产/消费。
4. 产生龙牙、龙血、破招、破罡、破军、龙牙·神兵和画角闻龙伤害事件。
5. 橙武窗口内命中后，将战意回复至 5。
6. 更新破军持续时间。

## 当前配置边界

- `gcdFrames`和任驰骋读条帧数为配置项。
- 默认配装来自 `天策大橙武5速.json`，离线计算结果为 43002 加速、5段和30ms延迟。
- 来源方案因原配装器互斥限制记录为牧云；研究运行配置显式覆盖为连营，但不改写来源文件。
- 撼如雷与任驰骋均使用顺序恢复充能：连续消耗两层后，第二层从第一层恢复完成时才开始计算恢复时间。
- 底层充能组件保留独立恢复模式，仅用于通用性和单元测试；橙武连营正式配置固定使用顺序恢复。
- 第一版假定技能命中，不模拟未命中和目标不可选中。
- 默认研究目标为“134级木桩·斩”，从第0秒全程处于斩杀阶段。
- 新进入战斗时为5战意、0层流血；起手技能实际施加第一层流血。

## 五段加速龙驭连营约束

- 5豆起手固定为“龙牙→灭→任驰骋”；撼如雷和橙武在任驰骋GCD末端开启，下一GCD从5豆龙牙开始。
- 任驰骋与雷绑定时必须先完成任驰骋读条，禁止在读条结束前施展雷，也禁止在激雷开启后再用一个GCD施展任驰骋。
- 每次开启激雷前必须为5战意。
- 激雷内禁止穿云。
- 激雷内补豆顺序为可用的破楼兰双灭、灭、断魂刺、龙吟。
- 三豆补豆技能在2豆时使用，龙吟最迟在3豆时使用；激雷尾段允许继续打低豆龙牙。
- 断魂刺默认只在激雷内、马上且不高于2豆时使用；橙武期间禁止使用。
- 特例：马上雷起手龙驭少于9层且刷新后的断魂刺可用时，第一次补豆固定提前断魂刺，再回到通常的灭优先级。
- 双雷可直接衔接时，前一雷结束为0/1豆可用“灭吟”快速补满；实现也允许灭后4豆时用龙吟溢出1豆换取系数，但仅限这一直接衔接窗口。
- 雷内使用过龙吟且下一雷不能直接衔接时，12发龙牙后停止追加第13牙；其余窗口继续按可执行时隙尽量增加龙牙。
- 雷可用而任驰骋等待过久，或当前龙驭为0层时，允许马下开启单雷，借雷内马下龙牙积累下一轮龙驭。
- 雷已可用但不足5豆时，技能决策以补到5豆为目标，不继续用马下龙牙破坏开雷准备。
- 任驰骋可在雷前置入雷外空档，用于构成类似“吟穿牙任灭雷”的跨窗口衔接。
- 稳态模式在激雷结束后的下一动作点下马并保存剩余龙驭；固定时长模式可在确定没有后续利用窗口时继续马上泄能。
- 在白皮书严格模式中，任驰骋层数溢出、橙武覆盖任驰骋、稳态雷外龙驭龙牙仍作为策略偏离；它们是游戏允许的行为，不再列为机制非法。

## 合法性、资源浪费与策略偏离

- 机制非法只包含游戏状态机不能执行的动作，例如战意不足的龙牙、马下断魂刺、马上直接任驰骋、CD或充能不足。
- 龙驭和战意溢出、高豆断魂刺、低豆开雷属于资源浪费统计，技能轴仍然合法。
- 雷外断魂刺、雷内穿云、橙武内非龙牙、低龙驭时未优先断魂刺、龙吟补豆后选择13牙属于白皮书策略偏离。
- `strict` 模式只生成符合白皮书策略的动作；`guided` 和 `free` 共享完整机制动作空间。
- `guided` 模式只在中途束搜索剪枝时使用白皮书偏好；完整技能轴最终仍按实际总伤害选优。
- 引导与自由模式允许钉住一条严格模式完整轴作为热启动世界线，有限束宽结果不得低于该已知合法基准。
- 所有导出结果必须重新经过确定性状态机重放并通过机制审计；资源浪费和策略偏离不阻止导出。

## 固定时长与稳态评分

- 固定时长模式允许搜索读取战斗截止时刻，以截止前总伤害为第一目标；终局龙驭不强制归零。
- 固定时长模式允许最后一轮激雷后的马上龙牙作为终局泄能，但必须单独统计。
- 稳态模式的动作生成不读取剩余战斗时间；用更长训练轴选出路径，再截取到指定时长评价。
- 两种模式都输出龙驭获得、雷内消耗、雷外消耗、任驰骋溢出和终局剩余层数。
- 终局资源只在伤害相同或近似相同时作为次级比较项，不能为了归零牺牲实际伤害。

## 数值引擎边界

- 状态机和伤害公式均为纯 JavaScript，单步计算不发生文件 I/O。
- 战斗面板、技能系数和奇穴参数均为普通配置对象，可在搜索开始前一次载入。
- Excel 工作簿和原配装器只用于离线生成对照样本。
- 对照样本中的静态 `finalDamage` 缓存不直接作为真值；必须用目标面板即时重算后写入 `goldenDamage`。
- 当前原生伤害按期望值处理会心和龙牙·神兵的 `307/1024` 触发概率。
- 斩杀阶段的灭按实际触发来源标记为普通灭或破楼兰附赠灭；两者共享技能动作，但事件、技能轴与计数汇总分开。
- 龙血沿用龙牙伤害链的额外4%会心。
- 灭、龙吟和穿云的伤害快照使用施展前战意；回豆发生在快照之后。
- 流血最多两层；龙吟刷新为普通品质，灭刷新为战心品质，过期后重新从一层开始。
- 首次施加流血后，经过一个受加速影响的跳伤间隔产生第一跳。
- 刷新流血只更新层数、品质和到期时间，不改变已经排定的下一跳节奏。
- 若跳点与刷新技能恰好同刻，旧流血先结算该跳，再应用刷新后的层数与品质。

## 破军触发窗口

- 龙牙施展后开启4秒破军触发窗口。
- 龙牙自身产生两次破军：一次来自龙牙，一次来自新开启的窗口。
- 窗口内后续主要技能每次产生一次破军。
- 断魂刺自身固定产生一次破军；若命中时窗口仍有效，则额外产生一次。
- 突自身不创建破军窗口；命中时若目标已有破军效果，则额外产生一次破军伤害。
- 任驰骋不产生破军；流血周期和自动攻击不按独立技能行追加破军。

## 突

- 只允许马下施展；马上施展属于机制非法。
- 调息时间18秒，不占GCD。覆盖搜索保留会改变结果的时序边界：主要技能前、主要技能后的最早帧、CD恢复后的首个可用帧和GCD末端；同一增益与CD状态之间的等价中间帧不重复重放。
- 自身伤害使用原配装器“突”行的固定伤害38.5、攻击系数0.1和完整原生伤害公式。
- 伤害增益参数已包含通常选择的4%+3%伤害秘籍；不在状态机中再次乘算，避免重复增伤。
- 突按自身命中时刻快照激雷、任驰骋和破军目标状态。

## 自动攻击

- 加速后的攻击间隔使用 `wideGcdFrames`，单次攻击系数为 `(wideGcdFrames - 1) / 160`。
- 进入战斗后，梅花枪法第一击在 `0` 时刻立即产生。
- 后续攻击沿第一击开始的固定节奏循环。
- 任驰骋读条完成、上马和下马都不重置下一击时刻。
- 每一击按自身命中时刻快照激雷、驰骋和马上状态，并通过原生 oracle 结算伤害。
- 自动攻击与流血恰好同刻时，采用自动攻击、流血、玩家动作的固定结算顺序。

## 连续延迟调度

- 内部时钟使用整数子帧刻度：`1帧=1000刻度`、`1ms=16刻度`。
- `frame`与`timeMs`是同一整数时钟的可读镜像，不参与独立结算。
- GCD基础值先由加速等级换算为整数游戏帧。
- 每次可执行间隔为 `GCD帧数 × 62.5ms + 总延迟ms`。
- 橙武在前一个GCD末端提前1帧开启时，第一发技能相对激活时刻为 `62.5ms`。
- 后续施展时刻使用连续毫秒累计，不在每次GCD后单独四舍五入为游戏帧。
- 覆盖判断为 `castAtMs < windowUntilMs`；恰好位于结束时刻的技能不计入。
- 增益持续时间、技能冷却、任驰骋完成时刻和两层顺序充能均使用相同时钟。

## 离线技能表重放

- 组合标签会被编译为一个动作包，例如“雷断魂刺龙牙”对应撼如雷、断魂刺和龙牙。
- `CW` 标记编译为当前 GCD 末端提前 1 帧开启橙武，因此不倒推影响本行主要技能。
- 龙驭在上一行耗尽后，重放器会在下一行主要技能前自动下马。
- 若该行同时包含断魂刺，则先在马上施展断魂刺，再下马施展主要技能。
- 每行分别核对主要技能施展前和结算后的战意；不一致时立即报告具体行号与技能标签。
- 离线技能表快照只用于回归测试，不作为状态机的运行依赖。
- 昆吾·弦刃、刃凌、无修·荒、特效·腕和速·震使用期望次数模型，在战斗截止时汇总结算；它们不生成虚构的逐次命中时刻。
- 装备期望层只增加伤害明细，不改变战意、增益、冷却或技能决策。
- 属性附魔先进入默认装备面板并影响全部技能伤害；伤害附魔与装备特效在技能轴结束后按期望值追加，并分别输出技能轴DPS、装备特效DPS和合计DPS，避免重复计算。
- Excel 对流血、梅花枪法和神兵使用平均次数/分布；事件模拟器保留用户确认的精确跳点和命中时刻，因此这些项目允许出现小幅结构差异。

## 激雷与橙武重叠模板

- 同时开启模板让橙武内5发龙牙全部享受激雷。
- 3秒重叠模板在激雷剩余3秒时开启橙武，默认5段配置下有3发龙牙享受激雷。
- 完全错开模板在激雷半开区间结束时开启橙武，橙武内龙牙均不享受激雷。
- 后两种模板使用等待动作精确定位窗口，仅用于机制隔离和伤害归因，不作为最终实战轴。

## 180秒无等待候选轴

- 候选轴以已通过技能合法性和逐行战意验证的原5段连营180秒轴为底稿。
- 橙武标记只在选定行的GCD末端提前1帧注入，不增加等待，不改变后续行的施展时间。
- 冷却到点策略选择每个50秒冷却后的最早合法行。
- 激雷对齐策略只在同行开启激雷时注入橙武。
- 避开激雷策略只选择可容纳完整6秒橙武窗口、且与任一激雷区间都不重叠的最早合法行。
- 候选轴回放时仍由状态机强制检查技能冷却、充能、GCD和最低战意；但不再与原轴的逐行战意快照相等比较，因为橙武会改变战意路径。
- 当前只注入主动，不局部改写窗口内技能，所以该结果用于决定下一轮优化范围，不是最终最优轴。

## 局部搜索边界

- 6秒橙武窗口对龙牙、龙吟、灭和穿云做完全枚举；5个施展位共枚举 `4^5=1024` 种组合。
- 18秒激雷窗口通常包含15个施展位，采用可配置束宽度的状态去重搜索，不宣称为全局穷尽。
- 搜索保留技能表中激雷、断魂刺和橙武的原行位置；任驰骋行暂不移动，其余行替换主要技能。
- 状态签名包含战意、龙驭、马上状态、流血节奏、冷却、增益和顺序充能；同签名只保留当前窗口伤害更高的路径。
- 激雷窗口排名靠前的若干候选必须重放完整180秒。只有合法且全轴总伤害高于当前轴时才会接受，否则保留优化前的轴。
- 任雷软绑定将每个配对激雷放在任驰骋前1行、同行、后1行或后2行，每个新位置都重新搜索对应18秒技能。
- 当前任雷研究保留全6个任驰骋行，只移动激雷；这是为了不让搜索依赖未确认的“仍在马上时重新施展任驰骋”行为。
- 全行自由雷位采用两阶段启发式搜索：先用当前技能轴粗筛所有行，再对排名靠前和原位近邻的雷位重排18秒主要技能。这不是全组合穷尽。
- 任何只在最后一组爆发出现的改进都需要做多截止点检查；若收益只在战斗结束前恢复，则标记为收尾策略，不直接并入稳态循环结论。
- 任驰骋位置搜索通过交换主要技能保持任驰骋总数不变，并保留行上原有的激雷、断魂刺和橙武标记。
- 每个任驰骋偏移候选都重新搜索从最早被交换行至对应激雷结束的联合窗口，随后完成180秒回放。
- 联合坐标迭代按任驰骋、激雷、橙武的固定顺序运行；每个阶段只接受能提高当前完整180秒总伤害的候选。
- 若某轮三个阶段均为零增益，则坐标迭代提前停止。这只表示当前候选集、束宽度与坐标顺序下的局部收敛，不表示数学上的全局最优。
