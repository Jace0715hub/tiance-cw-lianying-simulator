# 开发路线

## M0：机制规格与配置（已完成首版）

- 整数帧时间。
- 橙武、连营、龙驭结算顺序。
- 可配置 GCD、读条、CD和充能恢复模式。
- 独立 damage oracle 边界。

## M1：确定性状态机（进行中）

- 已实现战意、龙驭、马上/马下。
- 已实现雷、橙武、驰骋、流血和破军触发窗口。
- 已实现主要技能和GCD末端动作。
- 已实现原生加速等级到游戏帧的换算，并将延迟与游戏帧分开记录。
- 已实现连续毫秒窗口调度器，可批量比较多个加速值在30/60/90ms下的橙武覆盖数。
- 已实现加速帧档和 Excel 段位边界枚举；同一帧档可因延迟落入不同段位。
- 已将连续时钟合入完整状态转移，GCD、增益、冷却和顺序充能均使用统一刻度。
- 已实现龙牙、断魂刺及窗口内后续技能的破军触发次数。
- 已实现梅花枪法周期调度：入战立即首击，任驰骋与上下马保持原节奏。
- 已完成突的状态转移：仅马下可用、18秒CD、GCD内前置或末端施放，自身伤害以及命中破军目标时额外一次破军均进入事件结算。

### M5.5：局部启发式与精确验证器

- 先在18–30秒雷窗口、橙武窗口或失败修复窗口内实验最大收益最佳优先搜索、Weighted A*和分支定界，不直接替代完整180秒束搜索。

### M5暂缓项

- 暂不训练MLP或强化学习；先验证线性价值评分是否在固定预算下稳定增益。
