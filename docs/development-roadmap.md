# 开发路线

## 项目目标与执行原则

- 唯一主目标是在已确认机制、默认5段加速配装和180秒斩杀木桩环境下，找到并完整复演验证更高DPS的橙武连营技能轴。当前正式比较指标为完整180秒含突循环伤害；装备期望伤害单列，不把报表丰富度或工具完整度当作项目成果。
- 开发优先级固定为：可能改变候选排序的机制/伤害正确性 → 能打开新技能轴结构的搜索动作与高层锚点 → 能保留长期高价值分支的剪枝改进 → 只读诊断和导出。后两项必须服务于前两项。
- 新工具只有在满足至少一项时才开发：能够搜索现有动作空间未覆盖的结构；能够修复已有遥测证明的剪枝盲点；能够对新优解执行必要的完整合法性复验。单纯改善接口、报表、通用性或代码外观不进入近期路线。
- 所有搜索分支使用有界预算和不降级回退。`screen`无正收益则停止同类扩档；出现正收益才升级`fast/balanced`，并最终与当前全局最优比较。局部候选、粗评分或工具完成本身不构成阶段成功。
- 180秒30ms主线已在M5.51取得新突破：循环伤害`2,564,610,782.55`、总DPS`14,727,583.39`，较M5.50正式轴再提高`196,706.62`且机制违规0。新轴保持150个GCD主技能、雷表、橙武时点、龙牙数和龙驭增强次数不变，收益来自三雷下马/突联合迁移后让一次突与破军进入更高驰骋覆盖。按当前要求，配装计算器接入继续暂停，主线只验证并继续搜索橙武连营180秒轴；240秒和随机延迟同样暂缓。

## M0：机制规格与配置（已完成首版）

- 整数帧时间。
- 橙武、连营、龙驭结算顺序。
- 可配置 GCD、读条、CD和充能恢复模式。
- 独立 damage oracle 边界。

- 当前连营基准总伤害相对Excel为`+838,713.94`（`+0.0377%`），牧云大橙武为`+9,522,347.01`（`+0.3949%`），均通过既有`0.5%`门槛。但连营总误差包含龙牙`-5,598,276.89`、破军`+7,779,765.65`、两类流血合计约`-2,067,854.20`等分项抵消，不能仅凭总误差断言所有近优轴排序完全一致。
- M3剩余工作限定为一次有界排序敏感性核查：输入固定为当前正式轴、低约`928,750.43`的最近异构桥接轴、第6雷106行近优轴和质量多样性重启的最近末段轴。先用统一状态机重新生成技能分项与技能次数，再按现有事件模型、Excel离线单次权重以及“神兵·无双开场非满层”的边界情形复评名次。若名次稳定，关闭M3并继续搜索；若变化，再只修正造成翻转的机制或权重。不会为追求逐项小数完全一致而长期打磨Excel兼容层。
- 排序敏感性核查已完成。事件模型和按离线连营基准逐技能缩放的Excel分项场景都得到“正式轴→第6雷106行→异构桥接→质量末段轴”的相同名次；前三条相对正式轴的差值完全不变，质量末段轴只额外损失`1,719.42`伤害。
- 神兵·无双的开场动态层数后来在M5.28按“直接命中的玩家技能动作”单独核查，不再以派生伤害事件数量代替命中层数。报告保存于`output/lianying-ranking-sensitivity.json`，M3在当前候选范围内关闭。

- 单组翻盘阈值同样远离合理误差：原生口径需龙牙核心整体下调`62.68%`、灭整体提高`341.86%`、突/破军整体提高`353.96%`，或补豆技能提高`1,622.19%`。因此当前正式轴优势虽只有0.06579%，但不依赖某个接近临界的单一伤害系数。
- 这项结论只证明所列互斥技能组的仿射权重误差盒，不替代尚未实测机制本身。当前模型、默认装备、五段加速、30ms、斩杀木桩和固定180秒条件下，正式轴继续作为金标准。

### M5暂缓项

- 暂不训练MLP或强化学习；先验证线性价值评分是否在固定预算下稳定增益。
- 暂不把突并入主要技能束。当前机制中突不改变GCD、战意、龙驭或主要技能时间，固定主轴上的独立覆盖仍是更精确且更低成本的子问题。
- 暂不对完整180秒运行全状态A*，也不开放所有雷的无界全行坐标。
- 180秒确定性搜索已完成当前路线，不继续增加同类束宽、随机种子或高阶笛卡尔积。随机延迟、未知结束时间和非默认配装仍暂缓；按用户要求，配装器集成不进入当前主线。
